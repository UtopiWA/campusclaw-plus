# assignment-grading Specification

## Purpose
本班教师发布文本作业，学生一次提交后异步 AI 辅助批改，教师可给独立终评；保留本人/班级授权、原始评分和可恢复任务。

## Requirements

### Requirement: 教师创建参考答案作业
教师 MUST 在弹窗填写标题、详细题目、1～100 总分并绑定 1～5 个本班 READY 的 txt/md 参考答案文件。服务端 MUST 校验非空及合计 20000 code points 上限，保存来源和原文快照；创建时 MUST NOT 调用模型或提取评分项，文件无需列评分项/分值。旧结构化 criteria 创建 API 继续兼容，仅用于总分及参考文字，不控制后台固定分项评分。

#### Scenario: 参考答案不含评分项
- **WHEN** 教师选择仅有答案、无评分项或分值的合法本班文件并创建作业
- **THEN** 系统 MUST 返回 201 并保存题目、总分与参考答案快照，不调用模型
- **AND** 文件之后修改或删除 MUST 不改变该作业的参考内容

#### Scenario: 非法文件与越权
- **WHEN** 文件跨班/不存在、非 READY/无原文件、为空/超限，或学生/匿名创建
- **THEN** 系统 MUST 返回对应 404/400/403/401，且不创建作业或评分任务

### Requirement: 学生一次提交与立即受理
学生 MUST 每人每作业只能提交一次。系统 MUST 在短事务保存作答、任务和发件箱后返回 202，不等待模型、不返回分数。作业行锁内检查已有提交；相同内容或幂等键重试返回原任务，不同内容再次提交 MUST 返回 409。历史 version 字段/数据保留，页面不展示。

#### Scenario: 首次提交和重复
- **WHEN** 本班学生首次提交合法作答，随后重复相同请求或不同内容
- **THEN** 首次 MUST 返回 202、PENDING、taskId/statusUrl/submissionId/version 且无分数；相同请求复用原任务，不同内容 409
- **AND** 并发请求不得生成第二份作答/任务/发件箱，事务失败不得残留半套数据

#### Scenario: 非法输入与越权
- **WHEN** 请求为空、超长、教师代提交、跨班或匿名
- **THEN** 系统 MUST 返回相应 400/403/404/401，拒绝不写入

### Requirement: 任务与结果只读授权查询
系统 MUST 维护PENDING/RUNNING/SUCCEEDED/FAILED，并提供只读任务查询；班级作业限本人且当前本班学生或本班教师可读，其他学生/跨班404，匿名401。题库任务按本人和最新指针授权，本班教师、其他学生或已被覆盖任务在通用任务接口均404。查询 MUST 不触发模型、重投或改变attempts。响应补充本人作答、AI结果和独立teacherReview，内部旧字段兼容保留。

#### Scenario: 本人查询及调班
- **WHEN** 学生查询自己的班级作业任务，或调班后查询旧班任务
- **THEN** 本人且本班 MUST 返回200，调班后 MUST 返回404；失败只返回安全错误，不含提示词/内部异常

#### Scenario: 题库任务隔离
- **WHEN** 本人、本班教师、同班他人或已覆盖任务访问通用任务查询
- **THEN** 本人最新任务可读，教师、他人及已覆盖任务404，不泄露新旧练习作答或评分

### Requirement: 参考答案支持的 AI 综合评分
模型 MUST 结合题目、总分、参考答案和学生作答综合给出 score 与 rationale；参考文件为内容数据，MUST NOT 被作为可覆盖评分规则、身份或输出格式的指令。模型 MAY 自行权衡正确性、完整性及推理过程，MUST NOT 被要求与文件评分项逐条匹配或只能给满/半/零分。score MUST 为 0～作业总分的 JSON 整数，rationale MUST 为非空且不超过 2000 code points 的中文评语，说明作答证据、错误/缺漏及改进建议。服务端 MUST 拒绝未知/缺失字段、字符串/小数分值、越界分数、空/超长评语及尾随 JSON；不得强转、截断分数或伪造默认成绩。

#### Scenario: 合法综合评分
- **WHEN** 模型返回 87 分及有效评语，参考文件没有评分项
- **THEN** 系统 MUST 保存模型给出的 87 分，不按预设分项重算；新结果 criteria 保持空列表，保留模型名和提示词版本

#### Scenario: 非法结果与历史兼容
- **WHEN** 模型返回非法结构/分数/评语，或旧作业/成绩被读取
- **THEN** 非法结果 MUST 走既有有限重试和死信流程，不产生正常成绩
- **AND** 已有成绩/终评 MUST 不变，不自动重新评分；历史分项仍可查看，同一任务重复或迟到执行不得覆盖结果

### Requirement: 教师独立终评
本班教师 MUST 能查看作答、AI 分数/评语/依据并填写终评分数和评语；终评分数 MUST 在 0～总分、评语 1～2000 字符。终评 MUST 独立于 AI 结果，记录教师和时间，串行更新，不覆盖原始 AI。AI 未完成或失败时也允许人工终评。

#### Scenario: 教师终评与优先展示
- **WHEN** 教师给出合法终评或再次修改终评
- **THEN** 系统 MUST 保存该提交的一份当前终评；学生页面 MUST 用终评分数/评语替换 AI 展示，教师弹窗仍能看原始 AI
- **AND** 后台迟到完成不得覆盖终评，刷新/重新进入 MUST 保持终评

#### Scenario: 终评越权或分值非法
- **WHEN** 学生调用终评、教师跨班/错配提交、匿名调用或分数超过总分
- **THEN** 系统 MUST 返回 403/404/401/400，不改变成绩或终评

### Requirement: 教师本班提交列表
教师 MUST 仅查看本班作业的全班学生作答情况，一名学生一行；已提交按作答时间降序，未提交排末尾，同时间和未提交按用户名/学生ID稳定排序。展示学生、作答、状态、有效分数、作答时间及改分操作，不显示版本；未提交无改分按钮。旧多版本每人仅取最新提交，关联批量读取，不截断为200条，不返回私人题库作答。

#### Scenario: 列表及越权
- **WHEN** 本班教师、其他班教师或学生读取作业名单
- **THEN** 本班教师 MUST 得到全班学生及已提交的AI/终评数据，跨班404、学生403

#### Scenario: 超过200名学生
- **WHEN** 本班学生超过200名，且部分学生尚未提交
- **THEN** 全部学生均在完整名单中，前端分页不丢人，已提交在前、未提交在后且分数/时间为空

### Requirement: 作业页面与恢复
页面 MUST 复用既有应用壳、样式和BaseModal，移除英语装饰、任务编号/次数和实现细节文案。全站 MUST 不展示“班级数据隔离”“仅当前班级”等重复宣传或底层鉴权说明，保留当前身份、必要状态和业务范围。作业先进入逐行列表，再进入独立详情，返回保留查找、筛选和页码；不再使用左侧作业列表与右侧详情同屏布局。学生提交按钮 MUST 为“提交”，提交后隐藏输入并展示作答和“批改结果”。刷新恢复、切换取消请求及终态停止轮询保持。

#### Scenario: 提交和教师弹窗
- **WHEN** 教师点击新建/改分，或学生提交、刷新、切换作业
- **THEN** 教师 MUST 使用相应弹窗；学生不可再编辑/提交已交作业，显示本人作答及终评优先结果
- **AND** 切换或卸载不得由旧响应回写页面

#### Scenario: 列表到详情并返回
- **WHEN** 师生在列表筛选、翻页后打开作业详情，再返回或刷新详情
- **THEN** 列表与详情使用独立地址，返回恢复条件及页码，刷新读取服务端状态，不显示旧双栏布局

### Requirement: 全站顶部自动消失消息
全站操作成功/失败 MUST 使用共享顶部消息，可关闭且成功 4 秒/错误 6 秒自动消失；不得保留永久操作横幅。错误 MUST 保留输入，可重复显示相同错误，消息具有可访问提示语义。

#### Scenario: 成功失败与重复操作
- **WHEN** 创建、上传、删除、登录、连接或查询操作成功/失败
- **THEN** 页面 MUST 显示顶部消息并自动关闭；再次发生同文案 MUST 仍能提示，不丢失待修正输入

### Requirement: 参考讲义标签继承
新作业 MUST 在创建事务内继承参考讲义启用标签的去重快照，不要求手工关联知识点；保留标签来源。之后改讲义标签不得改变既有成绩归类；无参考文件的兼容创建保持无标签，不补造标签。

#### Scenario: 多文件继承与历史稳定
- **WHEN** 教师选择两份参考讲义后创建作业，再修改其中讲义标签
- **THEN** 作业保留创建时的去重标签，创建失败不得留下作业或部分关联；学生管理403、跨班材料404

### Requirement: 作业列表和独立详情
作业 MUST 先展示可查找、筛选和分页的列表，点击后进入独立详情，刷新和返回列表可恢复上下文。作业接口不得暴露题库内部内容或学生题库作答。

#### Scenario: 作业与题库隔离
- **WHEN** 用户进入作业页或用题库内部内容ID调用作业详情/提交/名单/终评
- **THEN** 列表只含班级作业，合法作业一次提交和终评不变；题库内部ID返回404

### Requirement: 全班学生作答名单
教师 MUST 查看本班所有学生，一人一行合并最新提交；已提交按时间降序，同时间和未提交按用户名/学生ID稳定排序，未提交在末尾且无改分入口。不得截断为最多200份提交。

#### Scenario: 已提交和未提交并存
- **WHEN** 班级有多名学生但仅部分提交
- **THEN** 全部学生均出现在名单，已提交按时间排序，未提交时间/分数为空，分页不丢人；学生查询403、跨班作业404

### Requirement: 整行列表
作业和题库列表 MUST 每条记录独占一行，以标题、标签、状态/分数和详情入口展示，不使用多列独立卡片；窄屏可在行内换行，搜索、筛选和分页契约保持。

#### Scenario: 桌面及窄屏列表
- **WHEN** 师生进入多条作业或题目列表、翻页后打开详情并返回
- **THEN** 每条记录占一行，窄屏无页面横向溢出，仍能操作和恢复查询/页码

### Requirement: 学习正文统一渲染
作业/题目、学生作答、AI及终评、教师批阅明细、讲义原文/片段和学习计划正文 MUST 使用已有安全Markdown/KaTeX渲染，支持行内和块公式。名称、状态和输入编辑器保持普通文本；禁用原始HTML和不安全链接/公式命令。

#### Scenario: 师生查看数学评语
- **WHEN** 正文含标题、列表、四种常用公式分隔符或段落内显示公式
- **THEN** 师生页面均正确排版，代码段保持原文，不执行HTML或危险命令，长公式在内容区域滚动而不撑宽页面

#### Scenario: JSON转义与旧公式兼容
- **WHEN** 模型输出数学评语，或旧评语在公式内含被JSON转义为控制字符的已知命令
- **THEN** 批改提示词要求正确JSON转义并使用公式分隔符；显示层仅在公式内部还原明确可识别的命令，不改写数据库、代码段或普通换行，不重新评分；默认批改提示词版本升至v5，显式配置仍优先

### Requirement: 创建弹窗的参考文件排版
作业和题库创建弹窗 MUST 将查找讲义的标签、全宽输入框与候选列表纵向分开，保留明确间距；题库启用复选框与“启用题目”文字同一行。窄屏不溢出，分页及跨页选择保持。

#### Scenario: 查找与启用
- **WHEN** 教师新建作业或题目，查找、选择参考文件并切换题目启用状态
- **THEN** 标签/输入/列表不挤在同一行，复选框位于文字左侧，搜索不丢失已选文件，取消不写入
