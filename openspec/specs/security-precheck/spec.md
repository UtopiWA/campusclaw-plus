# security-precheck Specification

## Purpose
提供可复查的安全自查证据，覆盖合成数据授权、密钥与依赖扫描、报告与延期复核、首次 Docker 复现与清理，区分真实缺口、工具失败和人员复核，保留现有业务行为。

## Requirements

### Requirement: 合成数据自查
自查 MUST 覆盖至少5个未登录接口、跨班访问/关键词检索、学生配置写入和直接越权批改操作；MUST 核对HTTP与数据库变化，合法本人提交不得误判漏洞。合成资源 MUST 创建后登记并在结束时按依赖清理，不覆盖已有账号或读取无关私人内容。

#### Scenario: 权限与数据不变
- **WHEN** 在指定私有配置的团队环境执行自查
- **THEN** MUST 记录401/403/404、跨班检索数量与无越权写入证据，真实失败不得冒称通过

### Requirement: 密钥与依赖完整扫描
安全入口 MUST 扫描全部本地可达Git历史、公开工作区、前端产物及团队现存运行日志，MUST 记录范围与工具版本；浅历史、缺产物或命令失败 MUST 以未完成退出。密钥命中 MUST 只输出类别/位置/指纹等脱敏元数据，不显示原值；依赖检查 MUST 保留高危/严重计数及未完成项。

#### Scenario: 缺范围或命中
- **WHEN** 扫描范围缺失、工具失败或发现未处置命中
- **THEN** MUST 非零退出并保留真实结论，不因忽略规则/降低阈值而写为零风险

### Requirement: 报告与延期复核
reports MUST 含六份固定报告及有答案/无答案/跨班问题草稿。初次 SEC-07 自查 MUST 实际触发技能并记录操作人、技能标识、状态、耗时、用量的实际情况；未知用量不得填0。技能 ID 和 Token 用量按用户决定搁置，MUST 保留原始红项，但 MUST NOT 列入本次同伴复核、修复任务或归档前置条件。另一成员尚未执行时 MUST 明确未执行，不能代签或提前归档。

#### Scenario: 审计不完整与同伴未执行
- **WHEN** 实际工具审计缺少技能标识或用量，且同伴尚未复现
- **THEN** MUST 记录SEC-07缺口，同伴报告只提供待办与复现命令，change保持活动

#### Scenario: 已搁置缺口不追加复核门槛
- **WHEN** 另一成员按交接完成页面功能、异步任务、至少两项授权安全检查和代码评审
- **THEN** MUST 按实际结果记录结论，不要求复现或修复技能 ID、Token 用量；其余收尾条件满足后可同步规格并归档，原始 SEC-07 记录继续保留

### Requirement: 首次 Docker 复现与清理
配置模板 MUST 显式给出团队项目、数据库和宿主端口，使新成员复制并填写凭据后可使用同一配置启动和验收。文档 MUST 说明 Docker/Python 前提、种子首次初始化与停用、模型依赖和隔离环境；MUST 区分自动合成数据清理、失败登记、手工验收数据及可复用镜像缓存，不得以全局 prune 清理其他项目。
Python 验收依赖 MUST 支持 MySQL 8 的完整认证路径，不依赖已有认证缓存，也不通过降级服务端认证插件绕过依赖缺失。

#### Scenario: 新机器复制模板
- **WHEN** 成员在新环境复制模板、填写私有凭据并按交接初始化
- **THEN** MUST 使用 `campusclaw_plus` 数据库和模板指定的宿主端口，初始化后停用种子；验收后可保留应用数据或仅移除自己的临时部署与文件，失败时保留诊断登记
