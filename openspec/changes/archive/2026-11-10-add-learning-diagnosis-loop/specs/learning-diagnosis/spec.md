# Learning Diagnosis

## Purpose

以教师维护的平面讲义标签和真实作答证据支持掌握度、学习计划及复习，统计使用明确规则；模型在服务端限定资源范围内安排学习任务，保护班级与个人学习数据。

## ADDED Requirements

### Requirement: 讲义平面标签管理
教师 MUST 在讲义页维护同班知识标签并批量设置讲义标签，支持按标签筛选；标签不得跨班使用，图谱与关系不再参与页面或计划。

#### Scenario: 替换标签和筛选
- **WHEN** 教师给讲义选择多个标签、清空或更名，用户按标签筛选
- **THEN** 关联原子保存，筛选返回相应讲义；学生管理403、跨班404，非法标签400/404且原数据不变，重复ID去重

### Requirement: 真实证据掌握度
系统 MUST 使用最近20份有效作答比例均值、教师终评优先、无证据null；未完成/失败不记零分，显示样本与依据。

#### Scenario: 终评和未知
- **WHEN** 教师修改终评或学生完成新练习
- **THEN** 画像按最新有效成绩更新且不重复计数，无记录标签保持未知

### Requirement: 专注掌握统计
教师学情 MUST 仅显示本班各标签掌握情况，学生学情显示本人掌握情况及学习计划；全班平均先逐学生计算再对有证据学生等权平均，明确无记录人数，不展示错误类型或教学建议。

#### Scenario: 样本不均衡
- **WHEN** 两名学生的有效作答次数不同
- **THEN** 全班平均按两人的掌握度等权计算，未作答者不计零，教师能查看本班明细，学生不得读取他人明细

### Requirement: 题库最新成绩与计划
系统 MUST 将本人每题最新成功批改与班级作业有效成绩合并，按每标签最近20条比例均值计算；题库未做不计零，重做不增加同题样本。学习计划在“我的学情”，使用当前启用题目及READY讲义，不依赖旧客观练习或前置关系，不展示底部调整历史及安排依据面板。

#### Scenario: 自主练习与重做
- **WHEN** 学生仅选部分题目作答，并重新完成其中一题
- **THEN** 未做题不进入分母，同题旧成绩被替换；计划完成事实保留，建议仍需主动请求并复用缓存

### Requirement: 受控模型学习计划
学生 MUST 可选填学习目标，并设置1至14天及每日10至120分钟；目标默认空，时间默认7天、30分钟。空目标按本人画像和真实候选资源生成建议，不猜测未知掌握程度。模型单次生成包含日期、预计用时、具体讲义或题目及学习方法的结构化任务，最多14项且每天不超预算；仅使用服务端提供的候选资源。未知掌握情况不得视为零分，明确复习目标允许选择已掌握标签；资源不足或目标不明确时返回说明，不回退成无关计划。

#### Scenario: 生成与复用
- **WHEN** 学生主动生成或有新成绩后调整计划
- **THEN** 相同目标、预算、学习事实及资源版本复用结果；新版本保留已完成任务，仅替换未完成任务，不在刷新或作答后自动调用模型

### Requirement: 模型输出与并发保护
系统 MUST 校验JSON结构、字段长度、候选资源ID、标签对应、日期/时间及任务类型；模型无工具和数据库写权限。外部等待位于事务外，通过认领、超时接管、版本和输入快照校验阻止重复与迟到覆盖。失败保留原计划，不保存部分任务，错误不含供应商原文。

#### Scenario: 不可信输出和过期结果
- **WHEN** 模型返回跨班/虚构ID、额外执行字段、超预算内容，或生成期间资源/学习事实发生变化
- **THEN** 拒绝保存并保留原计划，提示重试；目标/片段中的指令不会改变服务端授权或触发工具

#### Scenario: 未使用资源数组省略
- **WHEN** 模型返回合法REVIEW任务但省略questionIds，或合法PRACTICE任务省略materialIds
- **THEN** 本地补齐该未使用数组为空并执行完整校验，不额外调用模型；实际使用的资源数组缺失、null/错误类型、未知字段、跨班/虚构ID、标签不符、重复或超预算仍拒绝，旧计划在失败时保留

#### Scenario: 生成失败的脱敏诊断
- **WHEN** 模型请求失败、返回空白或输出未通过本地校验
- **THEN** 记录固定失败类别以区分依赖与输出校验，不记录目标、响应正文、提示词、原始异常或凭据；页面仍使用既有公开错误，不能将非法输出当成功或自动反复请求修复

### Requirement: 计划完成事实
阅读任务 MUST 可由本人标记完成；新练习任务仅在指定题目有任务创建后提交的成功批改时完成，不能手动跳过，完成不等于掌握。旧版本任务保留兼容，已完成任务不会因新计划或题目重答被取消。

#### Scenario: 练习与阅读
- **WHEN** 学生阅读讲义，或完成指定练习、仅有旧成绩、批改等待/失败
- **THEN** 阅读可手动完成；练习只在满足实际新批改条件时完成；旧成绩和等待/失败不能冒充本次完成，掌握度仍按统一算法计算

### Requirement: 学习权限和失败
个人资源 MUST 同时限班级/本人，教师管理限本班，模型等待不占长事务；无数据/资源或模型故障不得伪造成功。

#### Scenario: 权限矩阵
- **WHEN** 匿名、学生管理、跨班/非本人资源访问或模型失败
- **THEN** 分别401、403、404或明确依赖错误，无非法写入且已有学习事实不丢失

### Requirement: 学情独立子页面
学生“我的学情” MUST 通过独立地址展示掌握情况和学习计划，默认进入掌握情况；两个页面不能同时展示统计表和计划表单。师生掌握情况的标签列表须有总数、有效页码和10/20/50条分页，筛选重置到首页。

#### Scenario: 子页与少量标签
- **WHEN** 学生访问旧学情地址、切换子页或直接刷新计划页，且掌握情况不足一页
- **THEN** 旧地址进入掌握情况，当前子页可恢复，另一模块不挂载；不自动生成计划，掌握列表仍显示分页栏，教师无权进入学生子页

### Requirement: 页面文案精简
业务页面 MUST 保留标题、简短用途、状态、必要输入限制和操作确认；算法计算口径、后台实现和重复解释移入文档，不在正文或底部小字展示。

#### Scenario: 掌握统计和其他页面
- **WHEN** 用户查看掌握情况、讲义、作业、助手配置或会话页面
- **THEN** 不显示最近20次、阈值及后台机制的说明段落，仍能识别加载/错误/空态及删除、重答和输入限制

### Requirement: 界面链接样式一致
界面导航、返回按钮、计划资源入口及引用操作 MUST 不显示默认或悬停下划线，按钮式链接与普通按钮外观一致；保留可见键盘焦点和hover反馈。Markdown正文普通链接保留下划线。

#### Scenario: 资源和返回入口
- **WHEN** 学生查看计划中的讲义/题目入口，或师生通过作业/题库详情返回列表
- **THEN** 这些入口及其他界面导航无下划线，默认/hover/焦点均一致；正文普通链接仍可辨识且路由行为不变

### Requirement: 计划表单校验与建议模式
学生 MUST 在失焦及提交时获得非法天数/时长的顶部提示，空值、负数、零、小数和超范围值不得提交；服务端仍独立检查预算。学习目标选填，空白和缺省目标等价，默认输入为空；历史目标作为已有计划信息显示，不强制填入新请求。

#### Scenario: 无目标与非法预算
- **WHEN** 学生不填目标且预算合法，或输入非法预算后离开输入框/提交
- **THEN** 合法空目标发送建议请求，模型依据本人画像和候选资源规划并复用缓存；非法预算提示且不请求模型，旧计划保留
