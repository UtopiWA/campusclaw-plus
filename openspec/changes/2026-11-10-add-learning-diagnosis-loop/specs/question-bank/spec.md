# Question Bank

## Purpose

为学生提供同班教师维护的自主练习题库，沿用讲义参考答案与标签、异步AI批改和既有权限。作答不作为必交任务，每名学生独立保留每题最新内容和评分，教师管理题目但不读取练习正文或终评。

## ADDED Requirements

### Requirement: 教师题目管理
教师 MUST 管理本班题目的标题、题干、总分和参考讲义，继承启用标签；支持新建、编辑、停用和删除，编辑不得改变已提交的评分快照。

#### Scenario: 管理与归属
- **WHEN** 教师编辑题目，或学生/跨班用户调用管理接口
- **THEN** 同班合法编辑保存新快照；学生403、跨班404，失败整份回滚，现有讲义及标签不变

### Requirement: 私人最新作答
学生 MUST 只能提交和读取本人每题最新作答与AI结果，批改中禁止不同请求再次提交；相同幂等键重放返回原任务。完成/失败后可重新提交，覆盖旧正文和结果，保留必要任务元信息。

#### Scenario: 重答和并发
- **WHEN** 同一学生并发提交、刷新或批改结束后重答
- **THEN** 每题只有一份当前作答，等待中不同请求409、重放幂等；重答后不返回旧结果，旧消息/迟到执行不能覆盖新结果，提交失败保留原数据

### Requirement: 异步AI与私人权限
题库 MUST 通过现有队列/worker异步AI批改并返回202无分数，保留重试/失败/回收出口。题库不提供教师学生作答列表或终评。

#### Scenario: 隐私和恢复
- **WHEN** 本人刷新、教师或同班他人读取题库作答/任务，或worker停止后恢复
- **THEN** 本人恢复最新状态，教师作答接口403、非本人/教师通用任务访问404；待处理不丢失，恢复可完成，消息/日志不含正文或凭据

### Requirement: 列表到详情
题库 MUST 在侧栏独立入口展示可分页、搜索和筛选的题目列表，点击后进入可刷新、返回的详情；学习计划统一位于“我的学情”，不保留旧客观模板和错题练习入口。

#### Scenario: 查询和页面恢复
- **WHEN** 用户搜索题目、翻页后打开详情并返回，或学生完成重答
- **THEN** 列表上下文保留，详情只显示本人最新作答/批改，教师仅显示管理信息，五个视口主操作可用
