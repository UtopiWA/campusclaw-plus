# security-audit Specification

## Purpose

为教师提供本班技能执行和拒绝/失败动作的可回查安全审计，记录操作人、服务端时间、动作、对象、结果、稳定技能标识和真实模型用量/耗时，并保证查询受授权保护且不泄露正文或凭据。

## ADDED Requirements

### Requirement: 技能执行七类记录

系统 MUST 在助手成功执行技能并提交助手消息时，持久化操作人、服务端时间、动作类型、操作对象、结果状态、稳定技能标识、技能名称、真实模型 Token 用量和模型耗时。模型未返回用量或本轮没有模型调用时，用量和耗时 MUST 保持 `NULL`，不得估算或写成 `0`。成功轮次的助手消息与其审计字段 MUST 在同一事务提交，`done` 事件仍只能在该提交成功后发送。

#### Scenario: 成功技能轮次可回查
- **WHEN** 本班学生通过助手触发一个已绑定技能并成功提交助手消息
- **THEN** 教师按技能、学生和时间窗查询时 MUST 看到操作人、服务端时间、动作、会话/消息对象、成功状态、稳定技能 ID 和技能名称
- **AND** 返回的 Token 用量和模型耗时 MUST 来自供应商或服务端实际测量，未知值保持 `NULL`

#### Scenario: 无模型或供应商未返回用量
- **WHEN** 本轮使用固定文本答复，或模型供应商没有返回 `usage`
- **THEN** 审计中的 Token 字段和模型耗时 MUST 为 `NULL`
- **AND** 系统 MUST NOT 以 `0`、估算值或默认值替代未知用量

#### Scenario: 模型流失败
- **WHEN** 模型流在助手消息提交前失败
- **THEN** 系统 MUST 记录一条失败审计事件，包含操作人、时间、动作、会话对象、技能标识（若已选择）和失败状态
- **AND** MUST NOT 发送 `done`，也不得把失败写成成功

### Requirement: 拒绝与失败尝试留痕

当学生尝试修改技能或助手配置、越权提交教师终评，或其他已审计动作被拒绝时，系统 MUST 在返回拒绝响应前记录操作人、班级、动作、对象、结果/HTTP 状态、服务端时间和请求标识。拒绝记录 MUST NOT 改变原有 401/403/404 响应，也 MUST NOT 产生业务数据。审计写入失败 MUST 被记录为稳定失败类别，且不得掩盖原拒绝结果。

#### Scenario: 学生修改配置被拒
- **WHEN** 学生请求修改本班技能或助手配置
- **THEN** 系统 MUST 返回既有 403，配置与数据库 MUST 保持不变
- **AND** 教师按该学生和时间窗查询时 MUST 看到对应的拒绝审计记录

#### Scenario: 越权终评被拒
- **WHEN** 学生或跨班教师尝试提交教师终评
- **THEN** 系统 MUST 分别返回既有 403 或 404，成绩/终评数据 MUST 保持不变
- **AND** 审计 MUST 记录操作人、目标作业/提交对象和拒绝状态

#### Scenario: 审计写入失败
- **WHEN** 拒绝路径的审计写入因数据库故障失败
- **THEN** 系统 MUST 保留原 401/403/404 响应，不得因审计失败放行或改写业务结果
- **AND** MUST 以稳定错误类别记录该审计失败，供后续排查

### Requirement: 教师本班受保护查询

系统 MUST 提供教师按技能、操作人和时间窗回查本班审计的接口。班级 MUST 来自服务端当前用户；学生 MUST 得到 403，未认证请求 MUST 得到 401；跨班查询 MUST 返回空集合，不得泄露资源存在性。单次返回数量 MUST 限制在 1～100 条，时间窗最大 366 天；非法数量、倒置或超长时间窗 MUST 返回 400。

#### Scenario: 教师查询本班审计
- **WHEN** 教师按技能、学生和时间窗查询审计
- **THEN** 系统 MUST 只返回当前班级记录，并按服务端时间稳定倒序
- **AND** 每条记录 MUST 包含七类安全字段，未知字段以 `NULL` 返回

#### Scenario: 学生、匿名和跨班访问
- **WHEN** 学生查询审计、匿名请求审计，或教师查询其他班级的数据
- **THEN** 系统 MUST 分别返回 403、401 和空集合
- **AND** MUST NOT 返回其他班级的用户名、技能、对象或时间信息

#### Scenario: 非法分页或时间窗
- **WHEN** 请求的 `limit` 不在 1～100、`from` 晚于 `to` 或时间窗超过 366 天
- **THEN** 系统 MUST 返回 400，且不执行跨班或超大范围查询

### Requirement: 审计字段安全与快照保留

审计响应和持久化记录 MUST 只包含操作人、时间、动作、对象标识、结果、技能标识/名称、Token 用量、耗时和请求标识等安全元数据；MUST NOT 包含提示词、用户作答、引用正文、工具完整参数/结果、凭据、内部地址或供应商原始异常。技能被删除后，已记录的技能标识/名称快照 MUST 保留，不得因外键级联丢失审计事实；成功轮次的私人消息按既有会话删除规则处理，拒绝/失败事件和 MCP 工具审计独立保留。

#### Scenario: 敏感内容不进入审计
- **WHEN** 本轮提示词、材料正文、学生作答或工具结果包含可识别敏感标记
- **THEN** 审计响应和持久化字段 MUST NOT 包含这些标记或完整正文
- **AND** 审计查询 MUST 只返回安全元数据

#### Scenario: 技能删除后保留快照
- **WHEN** 教师删除一个已产生审计的技能
- **THEN** 历史审计 MUST 仍能返回该技能当时的稳定标识和名称快照
- **AND** 系统 MUST NOT 因技能删除而清空对应审计事实

### Requirement: 两路审计事实一致合并

成功技能轮次 MUST 以已提交助手消息为事实来源，拒绝、流前失败和终评拒绝等无法表示为助手消息的动作 MUST 写入追加式审计事件；查询接口 MUST 合并两路并按服务端时间和稳定次序返回，不得把同一成功事件重复写两份。

#### Scenario: 合并成功与拒绝记录
- **WHEN** 同一班级在同一时间窗内既有成功技能轮次，又有配置写入拒绝
- **THEN** 查询结果 MUST 同时包含两类记录，且按服务端时间稳定排序
- **AND** 同一成功轮次 MUST 只出现一次

#### Scenario: 未知字段保持未知
- **WHEN** 某条记录没有技能、用量或耗时
- **THEN** 对应字段 MUST 返回 `NULL`
- **AND** 系统 MUST NOT 把缺失字段伪造成 `0`、空字符串或推测值
