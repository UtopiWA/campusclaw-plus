# 等式与一元一次方程

## 知识点 M03：等式的性质

等式两边加上或减去同一个数，等式仍然成立；两边乘同一个数，或除以同一个非零数，等式仍然成立。两边不能除以零。

例：由 $x+5=12$，两边同时减去5，得到 $x=7$。所谓“移项变号”是等式两边同时加减的简写，并非任意改变符号。

常见错误：只在一边作运算、移项不变号，或在变量可能为零时直接相除。

## 知识点 M04：一元一次方程

一元一次方程可以整理成 $ax+b=0$，其中 $a\ne0$。求解依次去括号、去分母、移项、合并同类项、系数化为1；每一步保持等式两边等价。

例：$3x-4=11$，两边加4得 $3x=15$，再除以3得 $x=5$。代回原式：$3\times5-4=11$，成立。

应用题先设未知数，列出数量关系，再列方程，最后检查单位和实际约束。例：单价4元，总价28元，可列 $4x=28$，得到7件。
