# 正比例与一次函数

## 知识点 M05：正比例关系

正比例函数是 $y=kx$，其中 $k\ne0$；当 $x\ne0$ 时，$y/x$ 恒为k。图像是经过原点的直线。k为正时，x增大则y增大；k为负时相反。

例：$y=3x$，当x=4时y=12；若y=21，则可由3x=21求得x=7。

常见错误：把所有直线都看成正比例函数。$y=3x+2$ 不经过原点，因此不是正比例函数。

## 知识点 M06：一次函数

一次函数是 $y=kx+b$，其中 $k\ne0$。k决定倾斜方向和变化快慢，b是与y轴交点的纵坐标。正比例函数是b=0的一次函数。

由两点求解析式时，把两组坐标代入形成方程，再求k、b。例：直线经过(0,2)、(2,6)，可得b=2、k=2，因此y=2x+2。

常见错误：混淆斜率与截距，或计算斜率时分子分母的点顺序不一致。检查函数式时应将两个已知点都代入。
