# 作业、题库与学情

作业用于教师布置和批阅，题库用于学生自主练习。两者都绑定参考答案讲义，并继承讲义当前的知识标签。讲义标签后续改变，不重算已提交的成绩。

## 页面和操作

| 入口 | 教师 | 学生 |
| --- | --- | --- |
| 讲义与检索 | 上传、管理讲义和标签，按标签查找 | 查阅、检索讲义 |
| 作业与批改 | 查找作业，进入详情后查看全班作答、给终评 | 进入详情，一次提交并查看批改 |
| 题库 | 新建、编辑、启停、删除题目 | 查找题目、自主作答、查看最新AI批改、重新作答 |
| 教学与学情 / 我的学情 | 查看全班标签掌握统计和学生明细 | 查看本人掌握统计、生成及调整学习计划 |

作业和题库都先进入逐行列表，每项展示标题、标签及状态/分数，支持标题/题干查找、标签和状态筛选、10/20/50条分页。分页栏在零条或一页结果时也保留。点击记录才进入详情；详情可直接刷新，返回列表保留条件和页码。

“我的学情”分为“掌握情况”（`/learning/mastery`）和“学习计划”（`/learning/plan`）两个子页面，旧入口默认进入掌握情况。标签表始终显示总数、页码及10/20/50条分页；统计口径在本文说明，页面不展示算法小字。旧客观题模板和错题练习入口已移除。测试题目与作业按教师正常创建流程新增，不随应用启动自动导入。

## 创建作业或题目

标题、题干、总分和参考答案讲义均需填写。总分1～100，参考讲义最多5份，须为本班已处理完成且有原文件的讲义。题干、学生作答、AI与教师评语、讲义预览和检索片段均支持Markdown与公式；编辑框保留原文。公式支持`$…$`、`$$…$$`、`\(…\)`与`\[…\]`，代码块按代码显示；原始HTML和危险命令不执行。

系统在保存时记录参考答案和标签，不额外调用模型提取评分项。AI结合题目、参考答案和学生作答评分，并说明扣分或给分依据；参考讲义不必包含固定评分表。

批改提示词默认v5，明确公式分隔符和JSON反斜杠转义，`GRADING_PROMPT_VERSION`显式配置仍优先。旧评语若将`\frac`等明确命令转成了控制字符，仅在公式显示时兼容还原，不改历史评分或重新调用模型；普通换行和代码不作猜测转换。

教师改题会保存新版本，已经提交的作答仍按原题和原参考答案批改。学生填写期间若题目改变，提交会提示刷新并保留当前草稿。题目停用后学生不能继续作答；删除后从题库移除，已有学习成绩保留。

## 题库重新作答

- 每名学生独立保存每题最新作答；教师不能读取题库作答正文、AI分数或评语，也不能终评。教师仍可看标签掌握统计。
- 提交后显示待批改，后台沿用原RabbitMQ和worker处理，刷新后恢复最新状态。
- 批改完成或失败后可“重新作答”；批改中不能再次提交。
- 点击重新作答时可修改原答案或取消。新提交成功后替换旧正文和评分，等待新结果；提交失败保留原记录。
- 旧任务只保留队列处理所需的标识和状态，不保留旧作答或评分。旧任务链接不能读取新作答。

班级作业仍只能提交一次，教师终评优先。题库重答不会改变班级作业记录。

## 掌握度怎么算

每个标签取最近20条有效成绩，分别计算“得分÷总分”的百分比，再等权平均，保留一位小数。班级作业采用教师终评优先的成绩；题库同一学生同一道题只取最新成功结果，重做替换旧样本。

没做的题、等待或失败的批改不计零分。某标签没有有效成绩时显示“暂无记录”。例如作业80/100、题库10/20，掌握度为65%；不能把没有做的其他题加入分母。

| 掌握度 | 展示 |
| --- | --- |
| 无有效成绩 | 暂无记录 |
| 不足60% | 需要复习 |
| 60%至不足80% | 继续巩固 |
| 80%及以上 | 已掌握 |

班级均值先算每名学生，再对有记录的学生等权平均。甲20次满分、乙1次零分，班级平均50%；未作答者不进入均值，但计入“暂无记录”人数。

自主选题的成绩只反映已有作答表现，因此页面同时显示样本数和最近作答时间。一个作业/题目含多个标签时，各标签共享整题得分比例，不能据此断言每个解题步骤都已掌握。教师默认看累计数据，也可指定最长366天的范围。

## 学习计划

在“我的学情”的学习计划页点击生成。学习目标选填且默认留空；不填时，AI按本人的掌握记录和可用资源给出建议。没有成绩时从基础阅读和练习开始，不虚构薄弱点。也可填写具体目标，例如“应用题列式不熟，想先看例题再练习”。旧计划目标只在计划内容中显示，不填回新目标输入框。

默认7天、每天30分钟，可设1～14天、每天10～120分钟，均须为整数。非法输入离开输入框时提示，提交时再次检查；后端同样拒绝负数、越界、小数及非整数类型，不将小数静默取整。

模型根据本人掌握情况和候选资源选择具体讲义、题目，安排每天的阅读和练习，最多14项。后端检查资源、标签、任务类型及时间预算；时间是预计用时。没有合适资源时说明缺少什么，不生成虚构链接；目标留空本身不会阻止生成。计划概述与任务说明也支持Markdown和公式。

阅读任务可以标记完成；练习任务须在计划创建后完成指定题目并成功批改，再刷新计划更新进度。旧成绩、等待和失败不能自动完成新任务；完成不等于掌握。计划中的题目改版、停用或删除后，需重新安排。已完成事实保留。

已有计划的底部始终显示任务总数、页码和每页10/20/50条选项，即使只有一页或暂无任务；未生成计划时不显示任务分页。讲义和习题入口、返回按钮及界面导航不带下划线，正文中的普通链接保留下划线，键盘焦点保持可见。

有新成绩后主动点击调整，只替换未完成项；刷新页面不会重新调用模型。输入和学习事实未变时复用已有计划。生成失败保留原计划，可稍后重试；页面不展示调整历史和安排依据面板。

模型返回后还要经过本地校验，因此消耗Token并不等于计划已保存。目前兼容阅读任务省略空的题目数组、练习任务省略空的讲义数组；只在本地补空，不再请求模型。实际资源、标签、预算和未知字段仍严格检查。失败日志仅记录固定类别，便于区分模型请求、JSON、字段、资源或预算问题，不记录目标和响应正文。当前计划提示词版本为`bounded-study-plan-v3`。

每次实际生成或调整最多一次规划调用，含计划概述，不另调模型解释；网关沿用原超时及至多一次网络重试。单用户15秒冷却、同一用户在途请求不重复生成，单实例最多2个规划调用。题库/作业每次实际批改调用AI；讲义上传仍使用Embedding，标签和掌握统计不调用Chat。

## 数学测试内容

[测试题目清单](math-test-examples.json)包含16道题库题目、3份班级作业，覆盖有理数、分数、等式、一元一次方程、正比例、一次函数和勾股定理。按讲义标题绑定，不包含学生作答或成绩；标题以“测试练习｜”“测试作业｜”区分。重复准备时先按标题查重，不能覆盖已编辑的题目。

这些内容供人工验收保留，不是系统初始化数据。正常部署不会修改已有讲义、标签、账号或成绩。

## 更新与验收

沿用已有私有配置，不重新初始化账号：

```powershell
docker compose --env-file .env.team up -d --build --wait --wait-timeout 300
```

V12新增题库和最新作答指针，V13增加计划预算及生成认领字段，原迁移不改；现有讲义、标签及已发布作业保留，没有新增必填环境变量。已发布的旧客观作业仍按原快照处理，但不再新建这类模板。

人工检查顺序：教师绑定已上传讲义创建题目 → 学生查找并进入详情 → 提交、刷新查看评分 → 重答确认只显示最新内容 → 教师确认只能管理题目 → 检查学情样本数及列表返回状态。班级作业再检查一次提交、全班名单和教师终评；在“我的学情”生成计划，完成指定练习后刷新，检查任务完成及调整后保留记录。
