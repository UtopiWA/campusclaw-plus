# 安全与隐私规范

所有模块适用。权限由后端执行，界面隐藏和仓库公开均不构成授权。读写行为遵守 [主规格](../../openspec/specs/)；新增学生作答等写操作必须在独立 change 中定义，不沿用“学生不能写任何东西”的笼统限制。

## 1. 授权和资源访问

| 规则 | 检查动作 | 缺陷与处置 |
| --- | --- | --- |
| 默认拒绝，Bearer JWT 验签后回查当前用户 | 无令牌、篡改、过期、数据库禁用用户分别请求业务接口 | 仍返回业务成功即阻断；只信令牌旧角色同样不通过 |
| 班级边界来自当前数据库身份 | A 班用户传 B 班 ID、伪造 classId、修改绑定 | 跨班资源按既有 404/空集合，不返回存在性或元数据；检查数据未改 |
| 私人会话同时限本人和本班 | 同班另一学生读取/删除他人会话 | 不得以“同班”放行私人内容 |
| 教师管理材料、技能、智能体和 MCP | 学生直接调用管理 API | 必须 403，前端隐藏而接口成功属于越权 |
| 附件读取跟随材料授权 | 在线查看/下载/上下文接口使用不存在、跨班 ID 和异常路径 | 先归属查询，再验证存储边界；不能另开任意文件 ID/path 下载接口 |
| 公开入口严格列举 | 匿名访问登录、health、文档及业务接口 | 只放行既有公开入口；健康不列出班级/服务详情，业务依旧 401 |

使用当前 `CurrentUserService`、`SecurityConfig` 与组合归属查询，不把 Controller 参数拼进新的身份对象。新类型资源必须在 change 指定教师/学生/本人/班级矩阵和 401/403/404 判据。

## 2. 密钥与令牌

- JWT 密钥、模型密钥、数据库口令、演示口令和 MCP Token 只存在于私有配置；`.env` 不跟踪，镜像构建不复制它。配置样例只列键名的目标见 [运维规范](05-operations.md)，当前样例仍待任务 4.4 整理。
- JWT secret 至少 32 UTF-8 字节，密码保存 BCrypt。浏览器当前将令牌放当前标签页 `sessionStorage`，不得放 URL、日志或持久化到 `localStorage`；这是继承选择，不宣称具备 HttpOnly Cookie 会话。
- 当前退出是客户端删除令牌，服务端不撤销已签 JWT。若需要即时吊销或刷新令牌，先另建认证 change；不能把现状写成已支持。JWT 更换签名密钥后旧令牌失效，提前告知重新登录。
- MCP Token 采用 AES-256-GCM 版本密文，随机 IV，不回显明文；`MCP_TOKEN_ENCRYPTION_KEY` 是 Base64 编码的 32 随机字节，与 JWT secret 独立。当前无批量重加密流程，禁止直接更换密钥后继续使用旧密文；须经单独迁移设计或在受控演示环境重新登记服务。
- 泄露时先撤销/轮换相关凭据，停止公开受影响产物，再由维护者决定历史清理；代理不得自行重写历史、推送或删除远端仓库。证据只记录凭据类别和处置结果，不粘贴原值。

## 3. 输入、输出和出站请求

SQL 使用仓储参数绑定，动态排序/筛选用允许列表，不拼接原始查询。上传按扩展名、实际字节上限、UTF-8 和存储边界验证；不能把原始文件名变成服务端路径。用户 Markdown 禁用原始 HTML，公式交给已有渲染器，不直接执行模型返回的 HTML/脚本。

MCP URL 只允许既有 HTTP/HTTPS、规范化路径和精确主机白名单，不接受用户信息、query/fragment，不跟随重定向，不因失败自动扩大白名单。模型/Qdrant 地址由可信服务端配置提供，不接受提问或健康参数指定远端地址；开发允许 localhost 是环境配置，不是生产通配规则。

工具原始结果不可信，按现有规则先截至 1200 Unicode code points 再检测常见注入，不直接将原始结果交给模型或页面；当前安全摘要不能证明远端事实真实性。模板/技能/模型输出不得覆盖系统授权、请求任意工具或泄露提示词。新增工具必须走已有服务层、显式适配器和 schema，不引入 `eval` 或任意进程执行。

**负向检查：** 构造非法 URL、重定向、超长文本、未知工具引用、注入哨兵及跨班资源，分别核对拒绝结果和数据库未变化。任何放行、原文泄露或未处理异常都阻断该模块验收；不能只以“模型最后没照做”判安全。

## 4. 数据分级、留存和副本

| 级别 | 例子 | 规则 |
| --- | --- | --- |
| 可公开 | 代码、规范、合成样例、脱敏验收摘要 | 入库前检查来源和敏感标记，不能把测试生成物默认当公开 |
| 受限业务 | 班级材料、技能配置、统计 | 服务端班级授权；公开演示只用合成数据 |
| 个人学习数据 | 真实会话、作答、成绩/画像 | 本人/教师最小权限；未来业务须定义授权与删除，不写入公开证据 |
| 秘密 | 密码、JWT、密钥、MCP Token/密文 | 不作为文档示例，不写日志/镜像/前端；密文也不作为公开样例 |

演示业务数据默认保留到课程验收结束后 30 天，由维护者决定隔离环境归档/删除；本轮不新增自动清理业务。私有运行日志目标保留 7 天，原始本机测试报告 30 天，备份目标 14 天；脱敏课程总记录可随仓库保留。上述是团队运维策略，不是当前已有定时任务。

删除清单至少列 MySQL 业务记录、上传文件、Qdrant points、消息中的引用/工具快照、工具缓存、报告及备份。当前材料删除已有文件隔离和向量清理 job；有审计 MCP 服务不能硬删，审计保留到受控环境整体退役，不为了留存期绕过完整性约束。备份删除/过期与业务接口删除分开记录，不能只删一张表便宣称个人数据彻底消失。

## 5. 扫描与交付门禁

每次提交前检查本次差异和 Git 跟踪文件；基线交付前检查全部提交历史、镜像层/构建上下文、前端产物、日志与截图。先用 `git ls-files -- .env`、`git log --all --oneline -- .env` 检查私有配置路径；结果为空仅证明该路径未跟踪，不证明历史绝无密钥。

完整秘密检查按每个历史提交的文本快照执行，覆盖实际口令/Token 模式、PEM 私钥及凭据赋值。工具只输出脱敏结论、相对文件位置和命中类别；命中内容在私有环境核实，不打印真实值。合成测试口令须有测试文件上下文，不能用全目录白名单掩盖命中。缺少可执行扫描工具/记录就保留该验收未完成，不把手工浏览几页等同全量扫描。

依赖风险在新增/升级时和每周至少检查一次。前端可执行 `npm.cmd --prefix frontend audit --audit-level=high`，需网络，非零和不可达分别记录；Java/Python 结合依赖清单及选定扫描工具或官方安全公告审阅，记录工具/版本/日期与结论，不虚构未安装工具的结果。新增扫描依赖须经 change 评审，不能自动全局安装。

发现可达的高危/严重漏洞、凭据泄露、越权或敏感日志，停止相关发布，模块负责人整改，另一成员复核；误报及继承例外需写适用范围、理由、责任人和失效条件，不能用“已知问题”默许全部通过。基线记录仅在 `docs/lesson-07/README.md` 汇总实际结果，本轮不预填扫描通过。
