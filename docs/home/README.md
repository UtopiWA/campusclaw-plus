# 师生首页

登录默认进入 `/home`，也可从侧栏返回。登录前有明确目标页面时仍恢复原地址。

## 教师

- 顶部显示本班学生数、已发布班级作业数、批改中作答数和待人工处理数。
- 掌握度条形图展示有记录且掌握度最低的8个启用标签，点击进入该标签的班级统计。暂无记录单独列出，不算作零分。
- 提交环图可切换最近5份班级作业，分母为当前本班学生数，每位学生只取该作业最新提交。
- 最近作业与待处理事项最多显示5条。待处理指批改失败且没有教师终评的最新作答；点击进入对应作业批阅。
- “布置作业”“上传讲义”“新建题目”直接打开已有表单，不会代为保存。

班级作业不包含私人题库。教师首页不展示任何学生的题库作答或练习成绩。

## 学生

- 顶部显示待交班级作业、批改中作答、需要复习的标签及计划待办数。批改中包含本人当前可访问题目的最新练习。
- 继续学习展示已有计划的完成进度及最多5项待办，资源直接进入讲义预览或题目详情；没有计划时只提供计划页入口，不自动生成。
- 掌握环图区分已掌握、继续巩固、需要复习和暂无记录。图例可点击、可用键盘选择，进入对应状态筛选。
- 待交作业与最近批改各显示最多5条。最近批改合并班级作业和本人最新题库练习，按评分时间排序；作业优先显示教师终评。

掌握规则沿用[学习模块](../learning/README.md)。首页不展示后台编号、作答正文、评分依据或算法说明。

## 刷新与边界

首页进入时读取一次，点击刷新读取最新摘要。后台完成批改后不会实时推送到首页。学生完整计划仍在“我的学情 → 学习计划”中维护；首页只推导展示完成状态，不改数据库。启用标签没有有效成绩时属于暂无记录，未做的可选题不会计零分。

汇总接口为 `GET /api/home/teacher` 与 `GET /api/home/student`，身份来自服务端当前用户；匿名401，错误角色403。两者均不接受班级/学生身份覆盖，不调用Chat、Embedding或MCP。图表使用现有Vue/CSS/SVG，无新增依赖、迁移或环境变量。

## 简单验收

1. 教师登录，核对本班学生数及作业数；切换环图作业，进入学生作答列表核对提交人数。
2. 点击掌握条和暂无记录入口，确认学情筛选；从首页打开新建作业、上传讲义、新建题目，关闭或刷新后不重复弹窗。
3. 学生登录，核对待交作业、最新成绩及教师终评；题库重答只显示最新结果。
4. 检查计划进度和资源链接；点击环图图例进入掌握状态筛选。没有计划的学生进入首页不会生成计划。
5. 缩窄到手机宽度，检查图表、列表和按钮；用Tab/Enter进入图例或快捷入口，弹窗用Escape关闭。

本轮实际结果、模拟与真实环境的区别见[检查记录](review.md)。
